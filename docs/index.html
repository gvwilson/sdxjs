Software Design by Example

Overview

The best way to learn design in any field is to study examples, and the most approachable examples are ones that readers are already familiar with. These lessons therefore build small versions of the tools that programmers use every day to show how experienced software designers think. Along the way they introduce some fundamental ideas in computer science that many self-taught programmers haven’t encountered.
